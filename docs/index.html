Using the slides

Use the arrow keys to move, Esc for the overview and S for presenter notes. Click choices and evidence buttons when prompted. Trainer calculations need internet; open those decks early. Printed results are the fallback.

Before teaching

Rehearse room voting on the classroom network; labelled cards are the fallback. Unzip both deck downloads to the same folder. All figures are fictional training data. The reading check provides feedback and a targeted retry.
