Which method fits? A decision tree for four impact evaluation methods

Start at the top and answer each question for the evaluation you are reading or commissioning. GreenWaste training, Module 2, October 2026.

This tree is a starting guide. It helps you think through what each method needs and what would make it impossible. The order of questions follows how credible each method usually is, but other methods can still be possible: for example, with earlier data and no cut-off you could still plan a difference-in-differences. Every method also needs enough data and a large enough sample, especially when choosing between two options such as regression discontinuity and difference-in-differences. Evaluations are best planned before any data exist, whichever method is chosen.

Lottery (randomised trial)Groups were assigned by chance. Ask how the draw was done and who dropped out.
Difference-in-differencesCompares the change in participants with the change in a comparison group. Ask whether earlier measurements show similar paths.
Regression discontinuityCompares participants just either side of the cut-off. It describes those near the cut-off. Ask whether the result holds in a wider window.
MatchingCompares participants with similar non-participants. Ask what was not measured and how close the matches are.
No credible comparison yetAsk for another design or more data. Until then, read any difference as descriptive, not as the effect of the programme.
